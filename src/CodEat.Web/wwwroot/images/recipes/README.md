# Photos des recettes

Emplacement optionnel des photos locales : `<identifiant de recette>.webp`
(formats aussi acceptés, par priorité : webp, avif, jpg, jpeg, png).

Exemple : `42.webp` pour la recette dont l’identifiant est 42. Le titre peut
changer sans casser l’association. Utiliser de préférence une image de 800 ×
500 pixels ou plus, cadrée au centre ; le site affiche un ratio de 8:5.

Sans fichier, aucun encadré, espace réservé ni image fictive ne s’affiche.
Les photos sont publiques : n’y placer aucune image privée. Ajouter les fichiers
avant de reconstruire l’image Docker ; ils sont livrés comme les autres assets
du site. Le nom numérique évite les chemins dépendant du titre ou d’une URL
BookStack privée. Cette préparation n’ajoute pas de téléversement dans l’interface.
